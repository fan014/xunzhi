# 循知

面向学生的中文学习助手：上传教材、课件、笔记或截图，用一句自己的话描述学习进度，生成可阅读的讲义和可直接作答的复习题。讲义与题目都能回到原资料；答错后可按考点再练。

- 个人单机使用：浏览器界面 + 本地 Python/FastAPI + SQLite + 本地资料目录。
- 唯一模型配置：服务端 `DEEPSEEK_API_KEY`，文字理解、图表理解、讲义与出题共用。
- 无 Key 也能体验：`/offline` 提供明确标识的离线示例。

## 首次安装（Windows）

环境要求：Python 3.12（安装时勾选 “Add Python to PATH”）。

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env
REM 编辑 .env，填写 DEEPSEEK_API_KEY=你的 Key
```

需要在本机运行测试时，再安装测试依赖：

```bat
.venv\Scripts\python -m pip install -r requirements-dev.txt
```

## 启动

在 `D:\HUAWEI\1` 目录双击 `run.bat`（或在同目录打开命令行执行 `run.bat`）。默认访问 `http://127.0.0.1:8000`；无 Key 离线示例为 `http://127.0.0.1:8000/offline`。

```bat
run.bat
```

`run.bat` 会复用或创建 `.venv`、安装运行依赖，并调用 `scripts/run_server.py`。浏览器只在本机健康检查通过后打开，不会先打开连接失败页。关闭该窗口或按 Ctrl+C 即结束服务。

也可手动启动：

```bat
.venv\Scripts\python scripts\run_server.py
.venv\Scripts\python scripts\run_server.py --no-open
.venv\Scripts\python scripts\run_server.py --port 0
.venv\Scripts\python scripts\run_server.py --port 8010
```

- `--no-open`：只启动服务，不打开浏览器。
- `--port 0`：自动选择空闲端口，适合隔离冒烟；实际地址会打印在窗口。
- 指定端口被占用时，启动器会在打开浏览器前给出明确报错，并列出可用做法。
- 健康检查会校验本次实例 ID，避免误把端口上已有服务当成刚启动的实例。

## Windows 桌面版（本机独立窗口）

首次配置一次：

```bat
setup_desktop.bat
```

它会安装仅桌面版需要的 `pywebview`，并在桌面创建「循知」快捷方式。之后双击桌面「循知」即可打开独立窗口，不需要浏览器或输入地址。

- 窗口标题「循知」，可缩放、可最大化；使用 WebView2。
- 复用项目 `.venv`、`data` 数据目录与 `.env` 真实模型配置。
- 启动器先做健康检查：已有本项目服务就直接连接；没有才启动自带服务。
- 关闭窗口时，由桌面入口启动的服务会正常退出；已有外部服务不会被关闭。
- 重复双击会聚焦已有「循知」窗口，不会启动第二个后端访问同一数据库。
- 日志：`data/logs/desktop.log`。
- 排错可用 `run_desktop.bat`（保留控制台输出）。
- 错误提示覆盖桌面依赖未安装、WebView2 缺失、端口被其他程序占用和服务启动超时。

网页入口 `run.bat` 继续保留，二者共用同一份数据。详细实测见 `docs/00-项目快速上手.md`。

## 唯一模型 Key

在项目根目录 `.env` 中配置：

```
DEEPSEEK_API_KEY=你的真实Key
```

- 只在服务端读取；页面、接口与日志都不回显 Key。
- 不配置 Key 时，真实生成按钮禁用，但离线示例仍可完整使用。
- 学生的界面不会出现聊天模型、识图模型、出题模型或检索模型的选择项。

## 无 Key 离线体验

打开 `http://127.0.0.1:8000/offline`，或首页「离线示例」：

- 原创拓扑图与预置题库，第一轮 5 题。
- 可读讲义、打开引用、作答、判分、按错题考点再练、重置。
- 全程不调用模型、不写真实学习记录；页面顶部常驻「离线示例」标识。

## 使用流程

1. 上传新文件，或从「选择已有资料」中勾选已保存资料。
2. 为 PDF 填写物理页码范围（留空表示全部页）。
3. 用一句话写进度；默认「巩固 / 5 题」，可切换基础/巩固与 3/5/8 题。
4. 生成后在结果页切换「讲义 / 复习题」，作答并提交，查看答案、解析与引用。

失败、取消或从结果页返回时，已选资料、页码、进度与设置会保留在本机浏览器。

资料库可以长期保留超过 10 份资料；单轮生成上限为最多 10 份、所选文件合计 150 MB、所选 PDF 合计 40 页，均按本次最终选中范围计算。前端会随选择与页码调整即时判断并禁用生成，后端在创建任务前再校验一次。

## 数据与隐私

- 数据目录默认项目下 `data/`（可用 `XUNZHI_DATA_DIR` 修改）；包含 SQLite、原始资料、页图与缩略图。
- 生成时只发送：本次选中的资料内容（PDF 仅所选页）、进度原文、难度与题量；不会发送未选文件、其他学习记录、账号或设备信息。
- 首次生成前会展示外发范围并请求确认。
- 删除学习包只删讲义/题目/作答；删除原始资料会在确认框提示「被 N 个学习包引用」，确认后删除原文件与预览，历史成绩保留，引用显示「来源资料已删除」。

## 真实模型验收（隔离）

`scripts/smoke_real.py` 在导入应用前强制使用程序自建的临时数据目录，覆盖外部 `XUNZHI_DATA_DIR`，不会读取或修改个人学习记录；不使用模型替身；TestClient 关闭后释放隔离 engine，退出时清理临时目录并检查清理结果；评测报告只在显式 `--report` 时写出。无 Key 时直接安全退出，不发送请求、不读取用户资料、不输出密钥。

快速冒烟（场景 A，3 题）：

```bat
.venv\Scripts\python scripts\smoke_real.py
```

同资料不同进度的 A/B（同一套自制拓扑图与文字资料、相同难度和 3 题，仅改变进度描述）：

```bat
.venv\Scripts\python scripts\smoke_real.py --ab --report ab-report.json
```

输出说明：

- 终端只打印模式、各组状态、题量、A/B 可观察差异、`checks_ok`、`engine_disposed`、`cleanup_ok` 与报告路径；不打印 Key。
- `--report` 的 JSON 保留原始选定进度、讲义小节、题干与选项、答案、解析、引用来源文件/页码，供人工核对。
- 自动检查只覆盖状态、题量、4 个互异选项、答案范围、交卷前隐藏、引用能否映射回本次资料；H-1～H-5、L3 引用支持度与 A/B 差异质量仍为待评，不代表真实内容已验收。
- 只有在结构检查、engine 释放与临时目录清理均成功时才返回 0；任一项失败会返回非零，并在终端/报告中标明，不静默报通过。
- `--timeout` 可调整每组有界等待秒数；超时会尝试取消任务并记录为 timeout。

## 常见问题

**如何用键盘上传资料？**
按 Tab 移动焦点到「上传新文件」区域（有可见焦点框），按 Enter 或空格打开文件选择器；选择后仍复用原有的上传与拖放逻辑。

**生成按钮一直是禁用状态？**
看按钮下方原因：服务端未配置 Key 时、未选资料、页码非法或进度为空，分别有不同提示。

**PDF 页码填多少？**
使用文件物理页码（从 1 开始），需满足 `1 ≤ 起始页 ≤ 结束页 ≤ 总页数`，单次不超过 40 页。超出会在前端标红并阻止生成。

**扫描页没有文字怎么办？**
系统会按页面图像渲染并登记为图像证据，引用以「整页/区域」打开；不会把识别不清的文字当作答案唯一依据。

**浏览器先打开、页面却连不上？**
请使用 `run.bat` 或 `scripts/run_server.py`；它会等到健康检查通过后再打开浏览器。若仍失败，查看窗口日志中的端口或依赖错误。

**端口 8000 被占用？**
启动器会明确提示端口无法绑定。关闭占用程序，或使用 `--port 0` 自动选择空闲端口、`--port 8010` 指定其他端口。

**如何清理学习记录或资料？**
在「学习记录」页逐条删除学习包，在「资料管理」中删除原始资料；取消确认不会改动数据。**不要直接删除整个 `data/` 目录**，其中包含你的真实资料与记录。

**需要完全隔离的演示/测试数据怎么办？**
不要把测试指向真实 `data/`。设置独立数据目录后再启动，例如：

```bat
set XUNZHI_DATA_DIR=%TEMP%\xunzhi-demo
.venv\Scripts\python scripts\run_server.py --port 0 --no-open
```

该目录与真实数据互不影响；结束后可按需删除这个临时目录。

**如何备份数据？**
停止服务后复制整个 `data/` 目录到安全位置；恢复时放回原位再启动。不要用删除目录的方式“修复”问题。

**如何确认没有把 Key 写进页面？**
页面与接口只返回 `configured` 布尔状态；`.env` 已被 `.gitignore` 排除。

**测试会不会动到我的资料？**
不会。测试使用 `tests/.pytest-data`，与 `data/` 隔离。
